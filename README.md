# Итоговый проект: Веб-приложение для ведения блогов «Личный Дневник»

Веб-приложение на базе **Flask** и **SQLAlchemy**, реализующее систему регистрации и аутентификации пользователей, а также полный CRUD-функционал для создания, просмотра, редактирования и удаления личных записей (постов) с изоляцией данных по автору и управлением схемой базы данных через миграции.

---

## Технологический стек
- **Язык разработки:** Python 3.14
- **Фреймворк:** Flask (render_template, request, redirect, url_for, flash)
- **ORM:** Flask-SQLAlchemy (SQLAlchemy 2.0, relationship, ForeignKey)
- **Миграции БД:** Flask-Migrate (Alembic)
- **Аутентификация и безопасность:** Flask-Login (LoginManager, UserMixin, login_required), Werkzeug Security (`scrypt`)
- **База данных:** SQLite (`diary.db`)
- **Фронтенд:** HTML, CSS, Jinja2

---

## Архитектура Базы Данных

Структура БД спроектирована на основе реляционной модели и разделена на 2 связанные сущности с настроенными первичными (`PK`) и внешними (`FK`) ключами:

- **`users` (Пользователи)**: хранит данные учетных записей — уникальный идентификатор (`id`), уникальное имя пользователя (`username`) и хеш пароля (`password`). Связана с таблицей записей отношением «один ко многим».
- **`card` (Записи / Посты)**: содержит заголовок (`title`), подзаголовок (`subtitle`), основной текст записи (`text`), а также внешний ключ `user_id`, связывающий каждую запись с её автором.

## Инструкция по запуску

### 1. Подготовка окружения
Склонируйте репозиторий, перейдите в папку проекта, создайте виртуальное окружение и установите необходимые библиотеки:
```bash
pip install -r requirements.txt
```

### 2. Инициализация и применение миграций базы данных
Примените миграции для создания актуальной структуры таблиц в локальной базе данных `diary.db`:
```bash
flask --app main db upgrade
```

### 3. Запуск веб-сервера
Запустите приложение Flask:
```bash
python main.py
```
Сервис станет доступен в браузере по адресу: `http://127.0.0.1:5000`

## Маршруты и функционал приложения

### 1. Аутентификация и авторизация
* `GET /home` — Приветственная страница для неавторизованных пользователей.
* `GET, POST /register` — Регистрация нового пользователя с проверкой уникальности имени и хешированием пароля (`scrypt`).
* `GET, POST /login/` — Вход в систему и создание пользовательской сессии.
* `GET /logout` — Выход из учетной записи (`@login_required`).

### 2. Управление записями (CRUD)
* `GET /` — Главная страница (личный кабинет): отображает список всех записей текущего пользователя.
* `GET /card/<int:id>` — Страница просмотра полного текста конкретной записи (доступна только автору).
* `GET /create` и `POST /form_create` — Страница и обработчик создания новой записи с валидацией обязательных полей.
* `GET, POST /edit/<int:id>` — Редактирование существующей записи (доступно только автору).
* `GET /delete_card/<int:id>` — Удаление выбранной записи с проверкой прав доступа и уведомлением.

## Структура файлов проекта

- `main.py` — Основной файл веб-приложения Flask с ORM-моделями, настройками авторизации и маршрутами.
- `migrations/` — Директория с конфигурацией и версиями миграций базы данных (`Flask-Migrate`).
- `templates/` — HTML-шаблоны Jinja2 (`base.html`, `home.html`, `index.html`, `login.html`, `register.html`, `create.html`, `edit.html`, `card.html`).
- `static/style.css` — Таблица стилей для оформления и адаптивной верстки интерфейса.
- `requirements.txt` — Список зависимостей проекта для установки через `pip`.
- `README.md` — Документация проекта (текущий файл).
